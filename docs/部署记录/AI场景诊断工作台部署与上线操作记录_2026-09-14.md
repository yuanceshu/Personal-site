## 4. Vercel 项目配置

### 4.1 实验服务项目

从 GitHub 仓库 `yuanceshu/Personal-site` 新建项目：

- Project Name：`personal-site-experiment-agents`
- Root Directory：`services/experiment-agents`
- 生产分支：`main`
- Python/FastAPI 入口：根目录 `app.py`
- 不设置自定义 Build Command、Output Directory 或自定义域名
- `vercel.json` 固定 `sin1` 区域、Python 入口和 75 秒 `maxDuration`

环境变量只录入 Agent 项目：

```text
EXPERIMENT_AGENT_TOKEN    # Production 与 Preview 使用同一套实验 Token
LLM_BASE_URL=https://api.minimaxi.com/v1
LLM_API_KEY               # MiniMax Key，仅 Agent 项目
LLM_MODEL=MiniMax-M3
LLM_TIMEOUT_SECONDS=45
```

所有 Secret 使用 Vercel 隐藏环境变量；主站和 Agent 项目中的 `EXPERIMENT_AGENT_TOKEN` 必须完全一致。

### 4.2 主站项目

在已有 `main` 项目中配置：

```text
EXPERIMENT_AGENT_URL=https://personal-site-experiment-agents.vercel.app
EXPERIMENT_AGENT_TOKEN    # 与 Agent 项目完全一致
```

本次 Production 和 Preview 均配置了上述两项。修改环境变量后重新部署主站 Production，确保新变量进入新的部署。

## 5. 这次不需要配置的变量

不要因为参考静眠森而复制以下配置：

```text
JINGMIANSEN_AGENT_TOKEN
CRON_SECRET
DATABASE_URL
MINIMAX_*                  # 静眠森旧服务的命名，不是本服务的变量名
```

本服务只有一套 `EXPERIMENT_AGENT_TOKEN`，目前 Production 和 Preview 共用；`LLM_API_KEY` 只在实验服务项目中存在。没有 Cron 清理任务，因此没有 `CRON_SECRET`；没有跨请求状态，因此没有数据库或 `DATABASE_URL`。
