## 2. 部署边界

```text
apps/main                    # 个人主站与 Project 000
apps/jingmiansen             # 静眠森 Next.js Web
services/jingmiansen-agents  # 静眠森 Agno AgentOS / FastAPI
```

Vercel 使用三个 Project，Root Directory 分别为上述三个目录。浏览器只访问静眠森 Web 的 Next.js API；Web 服务端再用 `JINGMIANSEN_AGENT_TOKEN` 请求 AgentOS。AgentOS 使用 MiniMax M2-her，生产数据库使用 Neon pooled PostgreSQL，本地没有 `DATABASE_URL` 时回退 SQLite。

静眠森 Web 的正式页面为 `/`、`/xing-yue-xiang-hu`、`/witch-train` 和 `/rainy-night-cafe`。主站保留旧 `/works/jingmiansen/*` 的 308 重定向和由 `JINGMIANSEN_SITE_URL` 驱动的单向入口。
