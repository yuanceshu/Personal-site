Do not read when：修改作品内页、公共页头、后端或其他 App。

Source of truth：本文档负责当前首页方案与冻结边界；页面文案的可执行字面值以 `apps/main/content/home.ts` 和 `apps/main/app/page.tsx` 为准。

## 首页整体定版

首页的样式、文案、布局结构、素材、交互和响应式表现均已定版。除非用户明确指定首页的具体修改，否则不得自行调整；其他首页相关任务只能进行不改变定版表现的检查或必要修复。

## 页面目的

首页是个人作品与实验空间，让访客理解作者如何把 AI 带入行业、授课、产品与设计实验和个人创作，同时保留持续思考的入口。AI 是共同媒介，作品和实际判断是主体。

本次属于 `apps/main` 内的首页内容与表现，不增加 App、路由、服务、依赖、数据库或部署单元。

## Hero 冻结边界

- 保留当前晨光创作空间背景、问候与身份文案、蒙版、文字层级、响应式换行、首屏高度和底部 01–05 索引。
- Hero 索引顺序为：行业 → 实验 → 创造 → 思记 → 授课，使用独立的 `homeHeroSections`。
- 上方只保留 Logo 和 `PERSONAL LAB`；自然滚动后出现标准 `SiteHeader`。
- 桌面与手机使用独立图片源，AVIF 优先、WebP 回退；短屏和文字放大时允许自然增高。
- 不增加视差、轮播、滚动劫持或装饰动画。

除非用户明确要求修改 Hero，不得改动 `.morning-hero`、`.morning-hero__image`、`.morning-hero__inner`、`.morning-brand`、`.morning-copy`、`.morning-index`、`.morning-hero::before` 与 `.morning-hero::after` 的现有表现。冻结包括：

- 背景图、左侧暗色蒙版、底部渐变与图片裁切；
- Hero 文案、字号、字重、颜色、透明度、段间距和换行；
- 01–05 锚点的字号、字重、颜色、间距和位置；
- Hero 整体高度、布局、留白与滚动位置。

没有明确提到 Hero 的任务也不得修改 Hero；若任务涉及首页其他区域，必须先检查对首屏高度和滚动位置的影响，并保持 Hero 的冻结表现。
