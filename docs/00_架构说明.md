# 架构说明

Do not read when：只修改局部 UI、文案、单个组件或不跨边界的作品内部行为。

Source of truth：本文档负责当前拓扑与跨单元关系；精确路由、Schema、环境变量和运行参数以代码、`.env.example` 和 workspace README 为准。

## 1. 运行单元

```text
personal-site/
├── apps/
│   ├── main/                    # 主站、普通作品与实验作品
│   └── jingmiansen/             # 静眠森独立 Next.js App
└── services/
    ├── experiment-agents/       # 工作台与行业实验 FastAPI 服务
    └── jingmiansen-agents/      # 静眠森专属 Agno AgentOS / FastAPI
```

- `apps/main` 承载主站身份、Project 000、工具作品、行业 Demo 和其他普通作品。
- `apps/jingmiansen` 因独立视觉、导航、域名、受众和角色交互边界保持独立；与主站使用普通整页跳转，不共享组件或运行时。
- `services/experiment-agents` 可被多个实验作品共用部署，但模块、Schema、提示词、业务逻辑和权限按作品隔离。
- `services/jingmiansen-agents` 只服务静眠森，不扩展为全站 AI 网关。

页面数量、页面长度或动态交互本身不构成拆分 App/Service 的理由。新运行单元的判断原则见工作区技术手册。

## 2. 路由与访问边界

- 主站作品使用 `/works/...`；实验作品的精确路由由对应项目规格和 App Router 代码定义。
- 静眠森使用独立站短路由；主站历史 `/works/jingmiansen/*` 地址只作永久重定向。
- 主站通过 `JINGMIANSEN_SITE_URL` 建立单向入口；静眠森不显示返回主站的入口。这是发现边界，不是鉴权或绝对匿名。
- 角色聊天与实验模型调用均必须先经所属 Next.js 服务端代理；浏览器不直连 AgentOS、模型供应商或实验服务。

## 3. 数据流与持久化

```text
静眠森浏览器
  → apps/jingmiansen Route Handler
  → Bearer Token
  → services/jingmiansen-agents
  → 模型与有限会话存储

主站实验页
  → apps/main 作品专属 API
  → Bearer Token
  → services/experiment-agents 作品模块
```

- 静眠森会话是有限上下文缓存，不是长期记忆或用户档案；会话、删除和保留期以角色安全规范和服务代码为准。
- 实验作品是否持久化由各自规格决定。真实的跨请求恢复、多访客共享状态或并发一致性需求必须明确持久化和身份边界。
- 限流计数资源不等于业务数据库；不得用浏览器自报 ID 充当公网身份。

## 4. 安全与公开面

- 密钥、Token、数据库连接串和上游地址只存在对应服务端环境；不提交 `.env` 或 `.env.local`。
- 健康检查只返回最小状态；原生 Agent/API、内部清理与管理界面由独立凭据保护。
- 代码和日志不保存不必要的请求正文、完整模型响应、私密资料或完整匿名标识。
- 静眠森公开资源不包含现实身份、主站域名或未审核材料；实验作品不把模拟数据描述为客户生产事实。

## 5. 部署边界

四个运行单元分别部署，环境变量和凭据按单元与环境隔离。跨单元共享的 Token 只在对应服务端保持一致，Production 与 Preview 可使用不同值。

具体启动命令、环境变量和接口见目标 workspace README；某次上线发生的事实见 `部署记录/`。部署记录不得替代当前配置。
