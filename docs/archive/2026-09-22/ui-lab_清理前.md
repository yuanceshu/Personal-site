# UI 实验室实施记录

冻结与内容基线：2026-09-15 用户最终方案（3组10版）。2026-09-16 首版归档与验收完成；2026-09-17 UI实验室外壳按Apple Design重新设计并通过验收。未部署、未推送。

## 架构判断

1. 主站一级作品，不归行业 Demo 集。
2. `apps/main` 内按 `app/works/ui-lab`、`components/works/ui-lab`、`content/projects/ui-lab`、`styles/projects/ui-lab` 组织。
3. 不新建 App：外壳是静态 Next 页面与客户端控件，独立版本是静态素材。
4. 不加依赖：归档使用现有 esbuild，预览使用现有 Playwright、Sharp。
5. 不加 API、环境变量或服务；无真实 AI、交易、长期存储，刷新重置。
6. 只影响实验室及首页两个入口，不改正式工作台/岛见业务代码。
7. 分支 `feat/ui-lab` 从 `feat/island-travel` 当前工作目录建立，保留全部既有修改。

技术基线：[全站手册](../../../../00_项目总说明/00_个人作品站技术实施手册%20TECHNICAL_PLAYBOOK.md)、[设计基线](../../../../00_项目总说明/02_全站设计语言与交互基线.md)；内容决定：[资料入口](../../../../01_资料库/资料_UI实验室/README.md)。实现同时遵循主站、工作台和行业 Demo 的局部规则。

## 冻结策略

仓库 `archives/ui-lab` 保存冻结源码/构建说明；`apps/main/public/projects/ui-lab` 保存产物/预览。源文件只复制，不修改原件。本机路径和迁移明细放忽略档案，不随公开仓库发布。构建只消费归档源码；主站build不再生成快照。验收后seal文件哈希并拒绝覆盖，新版本用新目录。

iframe仅 `allow-scripts`；CSP禁止连接、外部资源、表单提交。链接限制版本内部。就绪只接受当前iframe.contentWindow的消息；超时提供恢复。大屏版本保留1440并适配，手机375自动适配窄容器；原貌限制单独披露。

## 验收结果（2026-09-16）

- 3组10版全部通过并标记 ready；4种 Skill，裸跑另计1版。公开素材约4.3MB，冻结源码约1.2MB。
- 每版1440×1000、375×812完整代表图及独立缩略图均已生成。内部滚动区域保留原布局，不拼接未展开内容；手机原版溢出按375px视口记录，不补响应式。
- 20次原版/快照同状态截图比对：8个静态版本像素差为0；Apple工作台桌面/手机差异约0.04%/0.10%；岛见Frontend约0.98%/1.51%。阈值为单像素通道差超过25；审看差异来自演示提示、本地导航及离线适配，不把像素指标当设计评分。本机系统字体是截图条件之一。
- 逐版关键交互、版本内部跳转、重新开始均通过。浏览器实际请求检查未发现版本外请求，控制台无归档引入异常；不是仅凭CSP宣称离线。
- UI实验室单元6项、浏览器21项通过；浏览器测试在开发服务及 `next build` 后的 `next start` 上分别通过。
- 工作台现有单元45项/浏览器10项、岛见单元9项/浏览器13项通过；`lint`、`typecheck`、`build` 通过。构建后逐文件及预览SHA-256保持一致。
- 外壳320/375/768/1024/1440px、812×375横屏、200%文字无横向溢出；键盘选择、可见焦点、Esc离开iframe、减少动态及高对比偏好通过。中性色文本/控件色值测试满足4.5:1/3:1。此为本机Chrome验收，不冒充跨浏览器或完整WCAG认证。
- 首页两个入口、全部版本选择、碰撞交换、分享/刷新/前进后退、比例同步/独立滚动、A/B、视口切换、返回组合、资源失败重试与非法路由404通过。Project000、行业Demo入口返回200；首页1024/1440无新增横向溢出，静眠森外链配置未改变。

## 维护与复验

从 `apps/main` 执行：

```bash
npm run dev
# 另一个终端：
npm run test:ui-lab
npm run test:ui-lab:browser
npm run lint
npm run typecheck
npm run build
```

生产构建复验：`npm run start -- --port 4189`，再运行 `UI_LAB_TEST_URL=http://localhost:4189 npm run test:ui-lab:browser`。测试不需要配置任何实验后端或模型凭据。

归档工具位于 `apps/main/scripts/ui-lab`，说明见 [冻结源码](../../archives/ui-lab/README.md)。已封存版本不得重新执行生成来“更新”；未来结果新增目录、来源档案、截图、测试与清单条目，验收后单独封存。正常主站构建不触发这些工具。公开manifest仅含清理后的说明和相对路径/校验值，原始路径与截图比对记录仅在Git忽略的本机档案。
