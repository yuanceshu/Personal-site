# 开发路线图

状态：正式 V1 已实现，待发布验收  
更新时间：2026-08-20

## 阶段 0：设计定义（已完成）

目标：让首页、Project 000 封面和 60 秒互动拥有可执行的页面结构与视觉规则。

完成条件：

- 首版范围和路由固定；
- 桌面端与移动端结构明确；
- 明亮入口站与 Project 000 的视觉连续性明确；
- 互动状态、文案位置与无障碍要求明确；
- 待用户确认的内容被显式标记。

## 阶段 1：首个可浏览设计切片（已完成）

目标：建立应用并尽早提供一个可识别真实方向的本地预览。

实现范围：

- 首页第一屏与 Project 000 入口；
- Project 000 封面；
- 60 秒互动的核心状态，允许先使用代表性预置内容；
- 基础桌面端与移动端布局。

完成条件：访客能认出这是袁策书的产品实验室，能一次点击进入作品，并完成互动主流程。

## 阶段 2：Project 000 完整叙事（正式 V1 已完成）

按既有八层结构补全，并将摘要式 MVP 扩展为分层案例：

1. 封面；
2. 60 秒体验；
3. 用户问题；
4. 研发过程；
5. 210 分钟取舍；
6. 体验设计；
7. 四地迭代；
8. 证据、不足与反思。

正式 V1 已增加实名核心协作者、精确 210 分钟结构、三组体验设计、四地版本日志、具体课堂观察、可复用资产、产品反馈回路与明确不足。主叙事控制在约 5 分钟，来源与过程证据使用原生展开区域按需阅读。

## 阶段 3：真实素材与隐私处理（正式 V1 完成，持续补充）

- 按页面需要核对 PPT、Word、视频与照片；
- 建立发布资产清单；
- 模糊内部工具界面和感言卡姓名；
- 检查视频中的画面、字幕、声音、通知、账号和文件名；
- 输出网页尺寸与格式，不覆盖原始文件。

当前已核对并进入网页：四地各一张课堂现场、山西封面、四地授课时间节点手稿、课堂道具实物图、三张课件静态图和一张整体虚化的感言卡合照。正式 V1 采用全静态图文，不发布 PPT 内嵌视频；内部工具界面仍不进入公开资产目录。

## 阶段 4：完整体验与质量验证（进行中）

- 移动端阅读与交互；
- 键盘操作、焦点、语义和对比度；
- `prefers-reduced-motion`；
- 图片尺寸、懒加载和页面性能；
- 元信息与作品独立分享；
- 类型检查、构建和关键交互测试。

已完成首页第二人称入口、公众号二维码关系出口、60 秒互动、作品级内容与样式隔离、静态图片预算和无障碍偏好适配；仍需真实设备扫描二维码与正式域名分享验收。

## 阶段 5：发布

- 确认域名与 Vercel 项目；
- 发布预览；
- 进行真实设备验收；
- 修复阻断问题后上线。

## 当前正式 V1 非目标

- 博客、MDX 内容系统或 `thoughts` App；
- CMS、数据库、账号和后台；
- 通用提示词生成器或聊天机器人；
- 灵眠、静眠森及相关叙事层；
- 复杂 3D、粒子背景或大型设计系统；
- 为未来作品预建空页面和抽象组件。
