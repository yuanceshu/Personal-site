目标：让首页、Project 000 封面和 60 秒互动拥有可执行的页面结构与视觉规则。

完成条件：

- 首版范围和路由固定；
- 桌面端与移动端结构明确；
- 明亮入口站与 Project 000 的视觉连续性明确；
- 互动状态、文案位置与无障碍要求明确；
- 待用户确认的内容被显式标记。

## 阶段 7：静眠森受众隔离与角色实时对话（历史实现，部署方式已由阶段 11 替代）

- 保留 `apps/main` 与 `/works/jingmiansen/*` 路径，不复制第二套网页代码；当前通过 `apps/main/proxy.ts` 为独立域名提供 `/`、`/xing-yue-xiang-hu`、`/witch-train`、`/rainy-night-cafe` 短路径。
- 独立域名只放行静眠森页面、素材和角色聊天 API；静眠森页面不渲染返回主站链接，并设置 `noindex, nofollow, noarchive`。
- 在 `services/jingmiansen-agents` 引入 Agno AgentOS，注册灵眠、菲莉卡和真理奈三个角色，使用 MiniMax `M2-her`；Next.js 服务端 API 代理 SSE，不向浏览器暴露 API Key。
- 删除静眠森固定点选话题，只保留自由对话；灵眠在首屏展开，菲莉卡和真理奈分别从魔女列车与雨夜啡庭入口打开原生模态对话，消息区有限高滚动且作品角色同一时间只打开一个。
- 使用本地 SQLite 保存有限的会话历史，让同一会话具备多轮上下文；不启用长期记忆、知识库、工具或全站数据库。

完成条件：

- 填入服务端 `MINIMAX_API_KEY` 后，三个角色都能从静眠森页面发起并流式返回对话；
- 通过主站路径和独立域名分别访问时，页面入口、跳转边界与 `noindex` 响应符合预期；
- Key、会话库和未公开资料均不进入 Git、客户端 bundle 或静眠森角色提示词。

公网发布门槛：

- 独立域名与主站均使用 HTTPS，AgentOS 不由浏览器直接访问，生产环境不依赖 `127.0.0.1`；
- 为角色聊天增加按 IP 或会话维度的限流、异常请求拦截和可观察的费用上限，避免公开入口被滥用；
- 日志、异常响应和监控信息不记录原始私密输入、API Key 或内部服务地址，并完成必要的日志脱敏；
- 真实第三方数据流、服务商配置和隐私风险继续保留在内部安全规范与部署记录中；依据 2026-09-05 用户明确覆盖，公开页面不显示相关披露或提醒；
- 完成 AgentOS 部署、健康检查、服务重启和模型调用失败时的行内错误／重试验收；失败不得暴露内部服务地址，也不得阻断普通导航。

## 阶段 10：静眠森角色初见舞台与专注会话（已实现）

- 灵眠、真理奈与菲莉卡共用“初见舞台—正式会话”结构：空会话展示环境、半身人物、角色开场白和三条即时发送的快捷短句；首条消息发出后收束为顶部身份栏与消息流。
- 真理奈与菲莉卡继续使用原生模态；桌面尺寸固定为约 `64rem × min(40rem, 82svh)`，移动端使用无圆角全屏会话。灵眠仍在首屏右侧或移动端内容下方展开。
- 助手回复使用自然文本流，访客消息使用低对比气泡；输入区改为贴底输入坞，“新对话”只在存在消息、错误或草稿后进入次级菜单。
- 关闭不清空页面会话或中断流式请求；初见与会话只以透明度和轻微位移交叉切换，并继续覆盖减少动态、减少透明度与高对比度偏好。
- 页面不展示 AI、模型服务商、MiniMax 或隐私提醒文案；真实数据流、服务商与运行边界继续保留在内部技术和安全文档中。

## 阶段 11：静眠森独立 App 与 AgentOS 上线（Production 已部署，验收收尾中）

- 静眠森网页、内容、样式和发布素材已从 `apps/main` 迁入 `apps/jingmiansen`，正式使用 `/`、`/xing-yue-xiang-hu`、`/witch-train`、`/rainy-night-cafe`；
- 主站只保留 `JINGMIANSEN_SITE_URL` 单向入口和旧 `/works/jingmiansen/*` 的 308，外链不发送 Referer；
- Production 允许收录并输出 canonical、robots、sitemap，Preview 禁止收录；
- 浏览器使用匿名 `visitorId` 和每角色独立 `sessionId`，保存最近 8 轮界面消息，刷新恢复，30 天过期；
- AgentOS 本地继续使用 SQLite，Vercel 使用 Neon Postgres；生产原生接口使用共享 Bearer Secret；
- “新对话”尽力删除服务端旧会话，每日 Cron 删除 30 天未活动会话；
- MiniMax 调用已限制输出长度、45 秒超时和 1 次重试；Agent Function 上限 60 秒；
- Web Project 上线时必须配置 WAF：聊天 POST 每 IP 每 10 分钟 20 次。

2026-09-09 线上核验确认静眠森 Production、Agent `/healthz`、Bearer 鉴权和正式域名均可用；Preview Agent URL 尚未配置，WAF 第 21 次请求、Cron 清理和主站 Production 旧址仍没有完整证据。灵眠重复回复的客户端流解析修复目前只在本地工作区，尚未由本阶段记录证明已发布。

完成条件：

- Agent 测试覆盖 Postgres 选择、生产配置、鉴权、删除和过期清理；
- Preview 实测三个角色 SSE、刷新恢复、角色/访客/session 隔离与新对话；
- 未授权 AgentOS 返回 401，健康检查不泄露信息，WAF 第 21 次返回 429；
- Production 可收录、Preview 不可收录，公开静眠森内容不存在现实姓名或主站域名。

购买域名后的后续操作：

1. 将根域名绑定静眠森 Web Production；
2. 更新 Production 的 `JINGMIANSEN_SITE_URL`，使 canonical 和 sitemap 使用根域名；
3. 在 Vercel 将 `www` 永久重定向到根域名；
4. 更新主站同名环境变量并重新部署，复核旧址 308 与无 Referer。

## 当前正式 V1 非目标

- 博客、MDX 内容系统或 `thoughts` App；
- CMS、全站数据库、账号和后台；
- 通用提示词生成器、全站 AI 网关或聊天机器人；静眠森角色服务是项目范围内的定制能力；
- 复杂 3D、粒子背景或大型设计系统；
- 为未来作品预建空页面和抽象组件。
