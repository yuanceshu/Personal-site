# 第二版网站优化说明

状态：已实施首轮
更新时间：2026-08-20

## 1. 目标

第二版把入口站从“能力宣言”调整为“袁策书主动欢迎访客”。访客应在 10 秒内知道创作者是谁、相信什么、可以从哪里开始，并能在作品结束后继续认识作者。

受众采用个人与专业平衡：同事、合作伙伴、行业访客和关注 AI / 心理学的同路人都能理解，但页面不为任何一类人建立独立模式。

## 2. 已确认文案方向

- 问候：你好，很高兴你来到这里。
- 信念：很多事需要一点运气。好在，努力会让好运更容易发生。
- 身份：我是袁策书，在金融行业做产品与售前。INFJ，喜欢 AI 与心理学，也还在认真生活、工作和学习。
- 邀请：这里记录着我一路工作、学习和试验留下的作品。如果你也在认真走自己的路，愿我们做彼此的学伴——岁岁成长，一路同行。

第二人称只用于问候、选择、互动和收束；Project 000 的事实、过程与证据继续使用客观叙述。

## 3. 公众号关系出口

公开账号：`小袁AI感雾`

网站介绍：不定期分享 AI 产品实践、学习心得与生活感悟。不追光，只生长。

原始截图来源于用户提供的微信资料。网页只发布裁切后的二维码，不发布原始微信页面；所在地、性别、关注数和原创篇数不进入网页。

二维码文件：`apps/main/public/profile/wechat-official-account-qr.png`

## 4. 互动调整

Project 000 的互动统一称为“60 秒体验”。原先逐项点击的三个伪选择改为一次补上需求、场景和约束，再查看前后对照；继续使用本地预置内容，不接入实时模型。

## 5. 非目标

- 不加入灵眠、静眠森或世界观入口；
- 不添加账号系统、数据库、CMS 或 AI API；
- 不添加邮箱与其他社交账号；公众号是本阶段唯一的持续关系出口。
