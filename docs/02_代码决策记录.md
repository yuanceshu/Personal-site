## 仓库与运行边界

- 使用一个仓库，按真实运行边界维护 `apps/main`、`apps/jingmiansen`、`services/experiment-agents` 和 `services/jingmiansen-agents`。
- 普通作品、工具作品和行业 Demo 继续放在 `apps/main`；页面数量或动态交互不自动触发拆 App。
- 静眠森因独立域名、视觉、导航、受众和角色运行时保持独立 App 与专属服务。
- 实验服务可以被多个实验作品复用，但业务模块、Schema、提示词、数据和权限按作品隔离，不发展成全站通用 AI 平台。

## 主站与内容

- 首页使用“晨光 Hero + 4 + 1 内容线 + 作品地图”；Hero 冻结范围以 `docs/07_首页内容线与晨光首屏.md` 为准。
- 首页内容分类、作品实体和技术运行边界分别维护；改变分类不搬迁代码、不改变稳定 URL。
- `/thoughts` 是主站内的静态精选板块，不建立博客、MDX、CMS 或独立 App。
- 普通作品共享站点身份、页头和基础可访问性规则；作品视觉和组件只有真实重复后才抽取。

## AI 场景诊断工作台

- 路径为 `/works/ai-solution-lab`；前端使用受控模板和 Zod 校验，后端使用 FastAPI/Pydantic 与显式 OpenAI-compatible 客户端。
- 模型只输出受约束结构，模板、组件、数据绑定和语义规则由确定性代码控制。
- 首版草稿只在当前标签页内保存，刷新清空；无账号、数据库、长期历史或跨设备恢复。

## 行业 Demo

- 行业 Demo 集路径为 `/works/demos`；岛见和食智助手是内部作品，不建立行业 App。
- 岛见默认真实 AI 只做意图理解；班次、金额、库存、订单和支付为浏览器内确定性模拟，刷新清空。
- 岛见公网真实模型调用使用主站代理和 Redis REST 原子滑动窗口限流；未配置或计数异常时关闭真实调用。
- 食智助手第二版沿用虚构资料，在实验服务的餐饮独立模块中以 Agno + MiniMax 执行三类受限 Agent；模型只负责理解、选工具和解释，来源、数字与模拟提案由确定性代码控制。不接数据库或生产业务系统。

## UI 实验室

- UI 实验室是主站一级作品，冻结 3 组 10 个前端版本，外壳只负责比较、预览和失败恢复。
- 冻结源码和产物不覆盖；新版本使用新目录。iframe 保持受限能力，不连接外部系统。

## 安全与验证

- 浏览器不直接接触模型密钥、Agent Token 或任意上游地址；所有凭据仅在服务端环境变量中。
- 需要持久化时先定义身份、范围、清理和一致性；浏览器自报 ID 不作为公网身份。
- 本地、Preview 和 Production 验收分别记录；历史部署过程见 `docs/部署记录/`。
