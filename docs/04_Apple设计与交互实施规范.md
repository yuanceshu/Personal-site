# Apple 设计与交互实施规范

状态：全站当前实施规范

更新时间：2026-09-10

本文把[全站设计语言与交互基线](../../../00_项目总说明/02_全站设计语言与交互基线.md)落实为前端实现约束。它适用于首页、Project 000、AI 场景工作台、Demo 合集入口及普通作品；静眠森和行业 Demo 的视觉例外按基线文档执行。

## 1. 目标情绪

访客应感到平静、清楚、可信，而不是“这个网站很像 Apple”。Apple Design 用于提升直接性、可预测性和完成度，不用于复制系统或官网外观。

## 2. 全站视觉基础

- 页面主体使用纸白、浅灰、深色文字与克制的分层材料；主要交互统一使用全站蓝色变量。
- 绿色用于成功状态，橙色用于提醒，红色用于错误；普通作品不得用状态色重建全局品牌外壳。
- 使用系统字体栈与统一的标题、正文、说明文字层级；大标题收紧字距，小字号保证清晰度。
- 优先复用全局设计变量和站点公共组件。作品专属样式负责内容结构，不复制页头、按钮和焦点基础规则。
- 圆角、边框、阴影与透明材料使用全局变量；新增规格先证明现有变量无法表达。

## 3. 导航与空间关系

- 页头中的姓名始终返回首页。
- 普通作品和工具作品使用统一站点页头，并明确当前作品身份与返回路径。
- Demo 合集入口使用同一作品集外壳；行业 Demo 主体可以沉浸展示，但应保留克制且明确的作品集返回入口。
- 静眠森可以使用专属导航和视觉，仍需提供清楚的返回路径。
- 页面进入、退出和返回遵守稳定的空间方向，不让装饰动画改变导航含义。

## 4. 控件、状态与动效

- 按钮、链接、表单、选择项和可点击行具有统一的默认、悬停、按下、聚焦、禁用和等待反馈。
- 反馈从操作来源附近出现；错误说明发生了什么及可执行的下一步，不只依赖颜色。
- 普通过渡使用短距离位移、透明度和必要的小范围模糊，不使用装饰性弹跳。
- 按压应即时响应；异步结果较慢时立即显示阶段、取消或返回能力。
- 动画不得阻止再次操作。状态切换应接受中断，并从当前视觉状态继续。
- 只有出现拖拽、投掷、手势跟随或复杂中断动画时才评估动画库；普通界面切换继续使用 CSS 与现有状态。

## 5. 作品差异与行业 Demo

- Project 000 可以采用编辑式长页面，AI 场景工作台可以采用应用式布局；两者共享外壳、基础控件和交互语言。
- 行业 Demo 根据目标用户、任务环境和行业信任线索建立自己的配色、信息密度和内容组件，不强制套用作品集蓝色外观。
- 行业风格不等于取消规范。每个 Demo 仍须满足反馈、层级、可控动效、响应式和无障碍要求，并在自己的项目文档中记录视觉方向。
- 独立视觉世界或行业 Demo 的专属组件不自动提升为全站组件；只有真实重复且稳定后再抽取。

## 6. 材料与排版

- 页面主体优先使用实体背景，半透明材料用于悬浮页头、操作栏等确实需要表达层级的位置。
- 不在玻璃表面继续堆叠玻璃卡片；阴影用于说明层级，不用于装饰全部容器。
- 大标题使用紧字距与紧行距，正文使用舒展行距；字号和间距使用相对单位或响应式 `clamp()`。
- 不用超细字重、大段全大写或过量装饰制造“高级感”；真实内容和真实素材优先。

## 7. 无障碍与适配

- 所有关键操作支持键盘，焦点清晰且不因程序聚焦产生大面积装饰边框。
- 触控目标在移动端保持足够尺寸，320px 宽度不得产生页面级横向溢出。
- `prefers-reduced-motion` 下移除非必要位移、缩放和模糊。
- `prefers-reduced-transparency` 下使用实体材料，`prefers-contrast: more` 下增强文字和边界对比。
- 页面结构使用正确的标题、区域、状态和选择语义；不能用视觉布局代替可访问名称。
