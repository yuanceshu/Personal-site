# Apple 设计与交互实施规范

状态：MVP v0.1  
更新时间：2026-08-20

## 1. 目标情绪

访客应感到平静、清楚、可信，而不是“这个网站很像 Apple”。Apple 的设计原则用于提升直接性、可预测性和完成度，不用于复制系统外观。

## 2. Purpose：只保留核心路径

- 首页只回答“谁、擅长什么、有什么作品”；
- 首个作品无需筛选，一次点击直接进入；
- Project 000 只有一个强交互；
- 不加入世界观、博客、搜索、登录、CMS 和通用 AI 工具。

## 3. Familiarity 与 Wayfinding

- 页头中的姓名始终返回首页；
- Project 000 顶部明确显示“作品 / 001”和“返回首页”；
- 页面进入与退出使用同一条正常导航路径；
- 使用“作品、认识我、返回首页”等普通信息词。

## 4. Response：即时反馈

- 按钮与作品入口在按下时立即缩放反馈，不等待业务状态完成；
- 互动不使用人工延迟或模拟生成等待；
- 每次点击只推进一个清楚状态；
- 结果变化由 `aria-live` 向辅助技术说明。

## 5. Motion：行为优先

- MVP 没有拖拽、滑动 Sheet 或速度投掷场景，不引入动画库；
- 按压反馈约 80ms，状态材料化约 320–360ms；
- 非手势内容只使用透明度、轻微位移、缩放和模糊；
- 不锁定输入，不播放必须等待的开场动画；
- `prefers-reduced-motion` 下移除位移、缩放和动画时间。

未来若增加手势驱动界面：

- 使用 Pointer Events 与 pointer capture；
- 1:1 跟随触点并尊重抓取偏移；
- 从实时显示值继续，不从目标值重新开始；
- 释放时传递速度，并按投影位置决定落点；
- 默认临界阻尼，不为普通出现动画添加弹跳。

## 6. Materials：层次而非装饰

- 页面主体使用明亮实体背景；
- 只有悬浮页头和图片说明使用单层半透明材料；
- 不在玻璃表面继续叠玻璃卡片；
- `prefers-reduced-transparency` 下改为实体纸白背景；
- `prefers-contrast: more` 下提高文字、边界和表面对比度。

## 7. Typography

- 默认使用系统字体栈；
- 大标题使用紧字距与紧行距，正文使用舒展行距；
- 所有字号与间距使用相对单位或响应式 `clamp()`；
- 不用超细字重和大段全大写文字制造“高级感”；
- 页面允许系统文字放大而不破坏布局。

## 8. Craft 检查

- 320px 以上不出现关键文字和控件溢出；
- 触控按钮有足够高度；
- 键盘焦点清楚可见；
- 图片有准确替代文本；
- 动画只使用合成友好的 `transform`、`opacity` 与小范围 `filter`；
- 真实内容和真实照片优先于装饰图形。
