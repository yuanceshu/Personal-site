# 仓库文档路由

本文件只用于选择下一份文档，不代替源码、配置、Schema、测试或领域规格。普通局部任务应只读取一份直接相关规格；只有同时跨越技术与内容边界时才读取第二份。

| 文档 | Read when | Do not read when | Source of truth |
| --- | --- | --- | --- |
| [`00_架构说明.md`](00_架构说明.md) | 修改 App/Service 责任、跨单元路由、数据流、持久化、安全或部署拓扑 | 局部 UI、文案、单个组件或不跨边界的修复 | 当前运行拓扑与跨单元边界；精确实现以代码和配置为准 |
| [`01_开发路线图.md`](01_开发路线图.md) | 判断项目当前状态、下一步或发布顺序 | 实现已明确的局部任务 | 当前状态与待办；不作实现规格 |
| [`02_代码决策记录.md`](02_代码决策记录.md) | 改变现有技术选择，或需要确认某项决定是否仍有效 | 普通实现、样式或文案修改 | 仍有效的仓库技术决定；详细历史在 archive |
| [`04_Apple设计与交互实施规范.md`](04_Apple设计与交互实施规范.md) | 修改主站共享外壳、普通作品 UI、基础控件、动效或无障碍实现 | 后端、文案、静眠森专属视觉，或有自己规格的行业 Demo | 主站共享前端实施规则；具体值以代码为准 |
| [`06_实验作品组织与接入规划.md`](06_实验作品组织与接入规划.md) | 新增实验作品、改变实验服务共享边界或决定是否拆 App/Service | 修改现有作品内部行为 | 实验作品的组织和接入边界 |
| [`07_首页内容线与晨光首屏.md`](07_首页内容线与晨光首屏.md) | 修改主站首页结构、Hero、Bento、首页文案或首页验收 | 修改作品内页、公共页头或其他 App | 当前首页方案与冻结边界 |
| [`product/00_内容信息架构.md`](product/00_内容信息架构.md) | 改变首页内容分类、作品策展关系或 metadata 语义 | 只改样式、技术边界或单个作品行为 | 访客视角的内容信息架构 |
| [`projects/`](projects/) | 修改某个已有作品的行为、内容边界或验收 | 修改其他作品、纯共享基础设施或仓库文案 | 对应作品当前规格；事实与素材回溯到对应资料包 |
| [`部署记录/`](部署记录/) | 核对某次实际部署、线上验收或历史故障 | 设计新方案或确认当前配置 | 已发生操作的证据；当前配置以代码、`.env.example` 和平台为准 |
| [`archive/`](archive/) | 追溯被替代方案、清理前原文或历史理由 | 任何普通开发、设计或内容任务 | 历史证据，不是当前规范 |

## Workspace 运行说明

本地启动、环境变量、精确接口和专项验证命令在目标 workspace README。只在修改运行方式、配置或对应接口时读取，不把其作为普通 UI 任务的必读文档。
