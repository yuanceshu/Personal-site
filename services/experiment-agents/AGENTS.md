# 实验服务协作规则

本目录只承载实验作品的 FastAPI/Pydantic 服务，不是通用 AI 网关，不读取或复用静眠森资料、配置和密钥。

## 按需读取

- 修改已有作品模块：只读对应源码、测试和 `../../docs/projects/` 下的该作品规格。
- 新增作品、改变模块隔离或服务共享边界：读取 `../../docs/06_实验作品组织与接入规划.md`。
- 改变跨 App 数据流、持久化、安全或部署拓扑：读取 `../../docs/00_架构说明.md`。

每个作品的 `schemas.py` 是接口结构权威，业务语义由对应 domain 逻辑和测试约束。密钥只存在服务端环境变量；日志不保存请求正文或模型完整响应。

修改后运行 `uv run pytest` 和 `uv lock --check`；数据契约变化时同步验证主站消费端。
