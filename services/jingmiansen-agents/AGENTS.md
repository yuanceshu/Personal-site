# 静眠森角色服务规则

本目录是静眠森专属 Python/Agno AgentOS 服务，不负责主站、Project 000 或其他实验作品。

## 按需读取

- 普通服务代码：只读直接相关源码和测试。
- 角色提示词或资料装载：先读取 `../../../../01_资料库/资料_静眠森/AGENTS.md`，再按它的路由读取对应人物档案与语言规范。
- 会话、隐私、公开接口或安全：读取 `../../../../01_资料库/资料_静眠森/01_项目文档/09_静眠森角色智能体产品与安全规范_v1.0.md`。
- 跨应用接口或部署边界：`../../docs/00_架构说明.md`；只有追溯旧选择时读取完整决策历史。

## 运行边界

- 网页请求必须经过 `apps/jingmiansen` 的 `/api/jingmiansen/chat`；浏览器不得直连 AgentOS 或 MiniMax。
- 运行时只使用已核对且允许公开的资料；新角色、工具、知识库、长期记忆、追踪或外部动作必须有明确需求与资料安全评审。
- 生产原生接口使用共享 Bearer Secret；健康检查仅为 `/healthz`；清理入口单独使用 `CRON_SECRET`。
- Key、服务地址和 Token 只在服务端环境变量中。日志不保存不必要的请求正文、完整模型响应或私密资料。
- SQLite/Neon 只保存有限会话历史，不作为角色长期记忆；会话最长保留 30 天并相互隔离。
- 缺少生产所需 Key、数据库或 Secret 时拒绝启动；静态网页不依赖角色服务可用。

## 验证

修改后运行 `uv run pytest` 和 `uv lock --check`。接口、环境变量或网页行为变化时同步检查 `apps/jingmiansen`。
