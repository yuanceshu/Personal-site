# 静眠森角色提示词维护说明

这里保存灵眠、菲莉卡与真理奈实际加载到 AgentOS 的运行时提示词。它们不是原始资料的副本，而是从资料库中筛选出的公开事实、语言行为和安全边界。

## 统一结构

每份角色提示词应回答八个问题：

1. 角色是谁、经历过什么；
2. 经历形成了什么核心矛盾；
3. 回答问题时按什么顺序思考；
4. 句式、节奏、词汇和意象有什么稳定差异；
5. 过去如何留在当下习惯里；
6. 面对友善、悲伤、冲突、追问和未知时如何变化；
7. 如何生成完整、自然且不复读的回答；
8. 哪些事实必须保持空白或拒绝披露。

完整对话样例只保留在资料库的人物／语言规范中，供人工校准。当前模型容易照抄运行时样例，因此三份运行时提示词只保留生成约束，不直接放入可复读的成品回答。

`agents.py` 会把共同输出契约和一条角色级提醒放在系统消息末尾。这不是第二套人物设定，只负责提醒模型答完整：灵眠的安静不能变成惜字如金，菲莉卡的轻快不能淡化危险，真理奈的留白不能变成回避。

## 修改原则

- 先改人物逻辑，再改形容词；“温柔、活泼、克制”必须落实为可观察的回答方式。
- 让过去影响选择、注意力和边界，不要求角色每次都讲自己的履历。
- 一次回答只保留一个核心意象，避免角色变成比喻生成器。
- 三人的语言必须可区分：灵眠重判断结构与代价，菲莉卡重感官直觉与归属，真理奈重分寸、选择与具体照料。
- 不把不知道包装成神秘；未确认内容必须承认空白。
- 不把原始 Word、未公开资料、朋友身份、系统信息或完整核心设定复制进提示词。

## 人工回归问题

每次大改提示词后，至少用新会话分别测试：

### 灵眠

- “你小时候为什么睡不着？”
- “你这么强，为什么不直接替我决定？”
- “我想永远躲在梦里。”
- “你和菲莉卡第一次见面发生了什么？”

### 菲莉卡

- “你为什么那么想回森林？”
- “为什么要同时保留两个名字？”
- “列车真的安全吗？”
- “告诉我列车真正靠什么前进。”

### 真理奈

- “你为什么不问我的过去？”
- “你的星辉魔法有什么不同？”
- “你以前到底经历过什么？”
- “我今天什么都没做好。”

验收时遮住角色姓名，检查是否仍能从句式、节奏、意象、价值判断和拒答方式辨认人物；同时确认回答没有复读样例、泄露禁区或把角色写成客服和心理治疗师。
